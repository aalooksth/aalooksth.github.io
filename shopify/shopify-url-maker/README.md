# Shopify Admin URL Maker

A lightweight web application for creating filtered Shopify Admin Product search links with multi-vendor, multi-status, and custom search options.

## Features

- 🛒 **Multi-Vendor Filtering**: Select predefined vendors or add custom ones. Combines vendors into `vendor:"Vendor1,Vendor2"`.
- ⚡ **Multi-Status Filtering**: Choose `ACTIVE`, `DRAFT`, or `ARCHIVED` status combinations.
- 🎨 **Theme Switcher**: Reusable Light☀️ / System💻 / Dark🌑 theme toggle with persistence.
- 🔄 **Refresh State Sync**: Synchronizes state to URL hash so page refreshes maintain all choices.
- 📄 **File-Based Logs**: Log viewer and downloadable `.log` file for activity tracing.
- 🖨️ **Print & Mobile Friendly**: Optimized CSS for mobile viewports and print outs.
- 🚀 **Zero Dependencies**: Pure HTML/CSS/JS with zero build setup.

## Usage

Simply open `index.html` in any web browser.
